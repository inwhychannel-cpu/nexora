Help — using Nexora

Download and start

  1. Click the Download button on the Home page — you get one file: Nexora.exe.
  2. Double-click Nexora.exe.
  3. If Windows asks about an unknown publisher, click “More info” → “Run anyway”. This is normal for new free apps.
  4. Nexora's home window opens. Allow microphone permission when asked.

How to use Nexora

  1. Choose your language at the top of the window.
  2. Click 🎤 Speak and say one simple command — or type it in the ⌨ box and press Do It.
  3. Nexora does the work and replies in your language.

Example commands

Say or type any of these:

"open word" "open chrome" "open youtube" "search for cats" "youtube search funny videos" "type my name is Ahmad" "open photos" "what is the time" "volume up" "close this"

Nexora also understands many commands in other languages — try yours.

The floating icon

The small Nexora icon stays on top of every window. Drag it anywhere with the mouse. Tap it to open a mini panel with 🎤 Voice, a ⌨ text box and a ⌂ Home button. Hide it from the panel, and bring it back from the main window.

Troubleshooting

🎤 Nexora can't hear meCheck your internet is ON and your microphone is plugged in and allowed. No mic? Type the command instead.
📂 Nothing opensThe program must be installed on your laptop first — for example, Word only opens if Microsoft Word is installed; otherwise Nexora opens Word online.
🛡️ Windows blocked the startClick “More info” → “Run anyway”. Windows shows this once for new apps it does not know yet.
📦 The EXE does not work for meUse the ZIP test version from the Home page instead, and follow the guide file (USER-GUIDE.md) inside it.
